## 📦 共享提交流程与质量管控

1. 用户可通过「1410知识库 -> 工坊」导出符合 `1410-KBS` 标准的纯 Markdown `.zip` 知识包，并向本仓库发起 Pull Request (PR)。
2. 所有提交的知识库由维护者审核管控：通过完整度与专业质量核验的古籍或专业知识库将标记为 **「精品」**（`"is_premium": true`），一般知识库不做精品标记。
